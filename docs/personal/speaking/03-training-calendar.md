# Training calendar — weeks 3–6 (Jul 20 – Aug 16, 2026)

**The daily protocol (unchanged from the handoff, ~2–2.5h):**
8 takes new block · 8 maintenance (2 × 4 older blocks) · 6 objection roulette · 4 cold drills (random topic, zero prep) · 4 evening re-records of the day's worst moments · ~20 min review (best + worst take only, ONE fix written) · morning warm-up 15–20 min (straw/hum, lip trills, 2 × 90s PREP) · evening unsaid log (one thought-but-not-said → the 30s version).

**Quality gate, every take:** landing planned before speaking, forward-only obeyed. No landing, no count.
**Rotation:** Mon/Wed/Fri sales · Tue/Thu identity & client stories · weekend opinions & personal.
**Voice stop-signal:** tight, scratchy, or throat-clearing urge → end the block. 30 takes is a vocal load; the hoarseness >2 weeks rule and the SLP recommendation in [10-learning-and-skills.md](../../strategy/sales/10-learning-and-skills.md) stand.

Block IDs → [01-block-library.md](./01-block-library.md). Roulette → [02-objection-roulette.md](./02-objection-roulette.md).

## Scoring template (Whisper verbatim transcripts, fillers on)

```
Date · Block ID · Take type (new / maintenance / roulette / cold / re-record)
1. Restarts per minute:            ← the #1 metric
2. Sentence completion rate:   %   ← target >90% by week 4
3. Fillers per minute:
4. Landing hit (planned final sentence): y / n
5. Open strength / close strength · dead-end ratio:
ONE fix for tomorrow:
```

Paste a transcript into a Claude session in this project and ask for scoring — the response format is fixed by the handoff: score the transcript, then exactly ONE drill for tomorrow. Not a list. From month 2, watch for cold takes converging with rehearsed takes — that's the skill generalizing.

**Sparring:** name a roulette card (or say "draw for me") and Claude plays the prospect in text — two pushbacks, then holds the line. Respond landing-first; then check yourself against the canon card.

## Trajectory checkpoints (calibrate, don't panic)

- **End of wk 4:** completion rate >90% on prepared material; fillers down 60–70% on rehearsed blocks; objection answers starting under 1s.
- **Wk 4–6:** plateau or regression = consolidation. Expected.
- **Month 2 (August):** ~40 blocks; cold ≈ rehearsed convergence begins; live calls noticeably smoother. If calling consistently, booking rate should move. *(Program started July; week 3 is Jul 20, so month 2 = August. Month 3 ≈ September: 60–70 blocks, land-first/forward-only on autopilot.)*
- **Recordings run 2–3 weeks ahead of live rooms.** The gap is social load, not skill — group sessions are the transfer environment, not a second exam.
