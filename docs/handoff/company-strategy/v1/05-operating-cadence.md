# 05 — Operating cadence

The weekly operating system. The strategy fails or works here: protected selling hours, agent-fed mornings, one publish block, one honest review.

## A. The founder week (template)

| Slot | Mon | Tue | Wed | Thu | Fri |
|---|---|---|---|---|---|
| **Early** | A9 Weekly Review (30 min, with the agent) | A1 batch ready | A1 batch ready | A1 batch ready | A1 batch ready |
| **AM block (90 min, protected)** | Call block — dental | Call block — dental | Call block — home services (scanner) | Call block — dental | Call block — industrial (engagers) + warm-book follow-ups |
| **Midday (30 min)** | Send drafted touches | Send drafted touches | Send drafted touches | Send drafted touches | Send weekly LinkedIn post #2 |
| **PM delivery block (3 hrs, protected the moment an install signs)** | Delivery / P0-leftovers | Delivery; LinkedIn post #1 rides the break | Delivery; **first hour = publish block** (Sanity queue + guest-post pitches) | Delivery | Delivery; **last 30 min = close-out:** export cockpit CSV → `state/exports/`, review A7/A8 outputs |
| **Late-PM flex (60–90 min)** | Booked audits and Growth Calls land here first; overflow displaces the delivery block hour-for-hour, never the AM block. The same-day rate letter (A3 draft + founder edit/send) outranks everything else that day | | | | |

**The honest hour budget:** selling 10 (AM blocks) + sends/review ~4 + publish 1.5 + delivery 15 (one active install) ≈ **30–31 hrs/week.** A second concurrent install pushes ~40. That arithmetic — not optimism — is why capacity N exists and why the install targets are staggered (02 §E). Agents cannot build a client's site or run their ad account; they can carry content foundations, build scaffolding, reports, and QA, which is what keeps delivery at ~15 hrs instead of 25.

Rules:
- The AM block is untouchable. If a prospect can only do 9am, that day's call block moves, not dies.
- When delivery load spikes, the install timeline flexes before the AM block does — tell the client early; the staged-billing punch-list structure (D8) is built for exactly that conversation.
- Same-day letter discipline: an audit or Growth Call without a same-day letter/48h SOW start is a dropped ball, logged as such.
- Email lanes: industrial sends go out in founder-reviewed batches ≤50; never batch-blast.
- If real life gives fewer hours, cut lanes (home services first), not depth.

**Diagnostic ratios (re-baseline every 2 weeks):** dials→booked, booked→run (show rate), run→close. Fix the weakest stage; never respond to a weak funnel by only adding volume.

## C. Linear hygiene (the culture fix)

The team has never closed an issue. That ends:
1. **Close on ship.** A8 closes done issues daily with a one-line note. Done-on-a-branch is not done; merged-and-live is done.
2. **One In Progress per lane.** Anything In Progress >5 days untouched gets a note or goes back to Todo.
3. **Issues map to plays.** New issues cite their play (P0–P9). Orphan work is a red flag in A9.
4. **The probe issues get created** (they exist only as a handoff doc today), and SAL-404 is closed as superseded by SAL-411.

## D. The Monday review (A9 output → 15 founder minutes)

One page, fixed shape: last week's numbers vs floor/target → two sentences of read per lane → this week's play focus → the top 3 decisions from 08 with defaults. The founder's job in the meeting: pick decisions, adjust lane allocation, nothing else. Strategy changes happen at the 30/60/90 checkpoints, not weekly.

## E. Checkpoints

- **Day 30:** P0/P1 closed; warm book swept; first real ratios exist. Decide: industrial lane passed its validation gate (keep daily block / shrink to LinkedIn-only); ads gate (P7) attempt or defer; home-services lane keep/cut; install #2 timing against actual delivery load from install #1.
- **Day 60:** close-rate reality vs the 25–40% assumption; capacity N pressure-test against actual delivery load; partnerships (P8) go/no-go.
- **Day 90:** full re-plan against targets. If ≥2 installs closed: scale (ads on the winning vertical, M2 niche pages, expansion bench opens). If <2: the funnel diagnostics say which stage broke — fix that stage, or revisit the focus decision. Write company-strategy v2.
