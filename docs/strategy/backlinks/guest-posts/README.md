## Anchor rules (do not break)

- **One exact-match anchor across the whole batch** (draft 03, "GEO agency"). Five
  DR-30+ links landing on a DR-10 site with keyword anchors is a penalty signature,
  not a strategy.
- One article = one host = one publication. Never place the same draft on two sites.
- If a host demands nofollow, keep the placement anyway if the site is real —
  corroboration for AI answers doesn't care about the nofollow attribute.
- If a host swaps which link they allow (e.g. bio-only), move the same target/anchor
  there rather than adding a second link.

## Host vetting (recap from the backlink analysis)

1. ≥1,000/mo real organic traffic (verify in Ahrefs, not the seller's screenshot).
2. Ranks for its own head terms; recent posts are not 100% sponsored link-outs.
3. In-content placement, article body — no footers, no sidebars, no author-page-only.
4. Topical: marketing, SEO, business ops, or the trade press of a served vertical.
