# SEO Content Strategy — Project Template

A reusable framework for launching SEO content projects in Claude Cowork. Works for any niche — e-commerce, SaaS, local services, or content sites.

## Quickstart

1. **Copy this folder** into your new project directory
2. **Fill out `PROJECT_INTAKE.md`** — sections 1-10 are the essentials (10 min). Section 11 is optional deeper context that improves accuracy.
3. **Upload your data files** — whatever you have:
   - Google Search Console exports (Pages.csv + Queries.csv)
   - Competitor keyword CSVs (SearchAtlas, Ahrefs, SEMrush)
   - Sitemap or crawl export
4. **Start the Cowork session** — paste or reference the filled intake. The AI adapts to whatever data exists.

## What's in the box

| File | Purpose |
|------|---------|
| `PROJECT_INTAKE.md` | Fill-in-the-blank intake form — business context, product structure, data, priorities |
| `DATA_REQUIREMENTS_GUIDE.md` | Reference: what each input unlocks, file specs, fallbacks when data is missing |
| `WORKFLOW_CHECKLIST.md` | Step-by-step process from discovery through delivery |
| `EXAMPLE_FILLED_INTAKE.md` | Completed example using the Liori Diamonds project |

## No data? No problem.

The template handles four scenarios:

- **Full data** (GSC + competitor keywords + categories) → complete audit, plan, calendar, revenue model
- **Partial data** (URL + some keywords) → content plan from gap analysis
- **New site** (competitors only) → plan built from competitor content gaps
- **Audit only** (GSC data) → quick-win updates + CTR optimization

## Typical outputs

A full project produces: SEO analysis Excel, content plan, editorial calendar, client-facing PowerPoint, revenue projections, and a KPI tracker. See `WORKFLOW_CHECKLIST.md` for the complete phase-by-phase breakdown.
