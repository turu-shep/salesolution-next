# Niche page prompts

Operator playbooks for turning the per-industry **copy-angle briefs** into live Revenue Engine
landing pages. Tracked in Linear project **SS Niches** (team SAL).

| Prompt | Use it for | Linear |
|---|---|---|
| `rework-existing-page.md` | **M1** — sharpen one of the 4 live pages to its dominant pillar + per-trade language (no new URL) | SAL-432…435 |
| `split-the-bundle.md` | **M2** — stand up a dedicated page for a single trade/specialty + turn the parents into hubs | SAL-436…443 |

**The briefs are the source of copy.** Read them at `/strategy/niche/{slug}` (gated; open on
localhost) or straight from the typed data in `lib/strategy/niches/briefs.generated.ts`. Slugs:
`roofing · hvac · plumbing · electrical · dental · med-spa · plastic-surgery · local-retail`.

Always read `prompts/_CONTEXT.md` and `docs/strategy/operating-concept-bring-convert-retain.md`
first. Run the **humanizer** on all copy before finalizing.
